# Focus Launcher — versão de teste

Launcher minimalista para Android, feito para reduzir o uso no piloto automático.

## Como instalar

1. Baixe o `FocusLauncher-beta-1.0.0.apk` em [Releases](../../releases/latest).
2. Abra o arquivo no celular e permita "instalar apps desconhecidos" para o navegador ou gerenciador de arquivos.
3. Aperte o botão Home e escolha **Focus Launcher** como launcher padrão.
4. Para voltar ao launcher antigo: Configurações → Apps → Apps padrão → App da tela inicial.

## Dicas

- Puxe o relógio para baixo para buscar apps.
- Toque longo no relógio abre as Configurações.
- As proteções (bloquear Reels/Shorts, TikTok) pedem para ligar o serviço de acessibilidade.
